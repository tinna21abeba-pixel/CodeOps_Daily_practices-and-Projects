# Asynchronous JavaScript & API Practice

A simple JavaScript project that fetches live dish data from TheMealDB API and displays it dynamically on a webpage.

## Features

- Fetches live data using the Fetch API
- Uses `async/await`
- Displays a loading state
- Handles API errors with `try/catch`
- Uses `finally` to restore the button state
- Dynamically renders dishes

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- TheMealDB API

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Open `index.html` with Live Server.
4. Click **Add Dishes** to load the meals.

## API

[TheMealDB](https://www.themealdb.com/) - Public meal API used to fetch dish data.
